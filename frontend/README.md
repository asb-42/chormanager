# ChorManager Frontend (M2+)

React + TypeScript + Vite + Tailwind + TanStack Query + React Router.
Desktop-first (Analyse §5.1). API: M1-Backend (`/api/*`, Dev-Proxy
auf `http://localhost:8000`, siehe `vite.config.ts`).

```bash
npm --prefix frontend install
npm --prefix frontend test      # Vitest
npm --prefix frontend run dev   # http://localhost:5173
```

Verträge: `docs/plans/2026-09-26_m0_erd-openapi.md` §3.
Konventionen: `frontend/AGENTS.md`.
